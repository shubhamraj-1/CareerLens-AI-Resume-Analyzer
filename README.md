# CareerLens – AI Resume Analyzer

CareerLens is an AI-powered web application that helps users
analyze their resumes and improve their chances of getting suitable jobs.

## 🚀 Features

- Resume Upload
- AI-based Resume Analysis
- ATS Score
- Job Role Matching
- Skill Gap Analysis
- Resume Improvement Suggestions
- AI Cover Letter Generation
- Mock Interview Support
- User Dashboard

## 🛠️ Technologies Used

- React.js
- Node.js
- Express.js
- MongoDB
- JavaScript
- Gemini AI API

## 📂 Project Structure

- `frontend/` – User interface
- `backend/` – Server and API
- `assets/` – Project assets
- `app.ts` – Application configuration
- `package.json` – Project dependencies
- `vercel.json` – Deployment configuration
